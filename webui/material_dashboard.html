🔌 Kết nối Model Context Protocol (MCP)

Liên kết Chatterbox TTS Studio với các IDE AI Assistant để sinh giọng nói trực tiếp từ mã nguồn.

info Giới thiệu về MCP

Model Context Protocol (MCP) là một chuẩn giao thức mở do Anthropic phát triển, giúp các trợ lý AI (LLM) kết nối trực tiếp với các ứng dụng, công cụ và dữ liệu cục bộ. Khi tích hợp MCP, AI trong IDE của bạn có thể trực tiếp gọi các công cụ của Chatterbox như sinh âm thanh (TTS), chuyển đổi giọng nói (Voice Conversion) và quản lý nhân vật mà không cần qua giao diện web.

code Cấu hình tích hợp (Configuration File)

Sao chép đoạn JSON dưới đây và dán vào file cấu hình MCP của IDE/Client của bạn: 

{
  "mcpServers": {
    "chatterbox": {
      "command": "python",
      "args": [
        "E:/Project/chatterbox/mcp_server.py"
      ],
      "env": {
        "CHATTERBOX_API_URL": "http://127.0.0.1:8000"
      }
    }
  }
}

Cách cấu hình trên các IDE phổ biến:

  • Cursor IDE: Mở Settings -> Features -> MCP, nhấn + Add New MCP Tool, đặt tên là chatterbox, kiểu là stdio, và đặt lệnh chạy: python E:/Project/chatterbox/mcp_server.py.
  • Claude Desktop: Thêm cấu hình trên vào file %APPDATA%/Claude/claude_desktop_config.json.
  • VS Code (Roo Code / Cline): Cấu hình trong file %APPDATA%/Code/User/globalStorage/saoudrizwan.claude-dev/settings/cline_mcp_settings.json.
